# Std 9 Social Science · Chapter 4 · National Movements in India

A cinematic, teacher-led classroom presentation for the Gujarat Board (GSEB) Std 9 Social Science chapter
"National Movements in India" (textbook pp. 23–29). It has 41 slides in 9 acts and is built for a 16:9 classroom TV.

## How to use
Open `National Movements in India - Presentation.html` in Chrome or Edge. It is one self-contained file and works offline.

| Key | Action |
|---|---|
| → / Space / Page Down | next step / next slide |
| ← / Page Up | back |
| M | chapter map (jump to any slide) |
| N | teacher notes for the current slide |
| F | fullscreen |

There are also on-screen buttons (Prev, Next, Chapter map, Notes, Fullscreen), and you can click the left or right edge of the slide.

## Source
`src/slides.html` holds the slide markup, `src/extra.css` the chapter styles, `src/nodes.py` the timeline data and `src/img/` the textbook figures.
The deck is assembled with the social-science-chapter-deck engine (`build_deck.py`).

## Pictures
Textbook figures are named `fig-*` and `<person>.jpg`. Historical photographs, stamps and maps from Wikimedia Commons are prefixed `w-`.
`src/image-sources.txt` lists the Commons file behind each one and `src/image-licenses.json` its licence and author. The last slide of the deck credits them all.
