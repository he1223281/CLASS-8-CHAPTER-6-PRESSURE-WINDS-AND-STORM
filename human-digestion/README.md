# Digestion in Human Beings — classroom presentation (Grade 7, Curiosity Ch. 9)

Open **`digestion.html`** in Chrome or Edge. It is a single file and needs no installation.

## Controls
| Key | Action |
|---|---|
| → / Space / Page Down (clicker) | next reveal, then next slide |
| ← / Page Up | back |
| F | fullscreen |
| O | slide overview |
| N | speaker notes in a separate window (drag it onto your laptop screen) |
| R | replay the current animation · P pause / play |
| Home / End | first / last slide |

The Next button shows what the next click will do (e.g. “Show what happens when we chew”).

## Structure (26 slides, 6 acts)
1. **The Mystery** — one bite, life processes, entering the body, why food must be broken down, the alimentary canal
2. **The Journey** — chewing, why small pieces help, saliva & starch, Activity 9.1 (iodine), tongue & swallowing, the oesophagus wave
3. **The Transformation** — stomach (churning, digestive juice, acid, mucus), the mucus shield, Beaumont (1822), into the small intestine, ~6 m reveal, the digestion team, bile, pancreatic & intestinal juices
4. **The Absorption** — finger-like projections (villi), nutrients into blood, blood carries them everywhere
5. **The Clean-up** — large intestine (water & salts, stool, friendly bacteria), rectum, anus, egestion
6. **The Big Picture** — continuous recap of the whole journey, finale

## Editing
Source is in `src/`. After editing run `python3 build.py` to rebuild `digestion.html`.
Fonts load from Google Fonts when online; offline, system fonts are used and everything still works.
